# Travel Agency Website (TravelX)

## Project Overview

This project is a fully responsive travel agency website developed as part of an assignment. It includes multiple pages such as Home, About, Destinations, Packages, and Contact, designed with a modern UI/UX.

## Features

* Responsive design (mobile, tablet, desktop)
* Navigation bar and footer on all pages
* Destination listings with search functionality
* Travel packages with pricing details
* Contact form with validation
* Clean and modern user interface

## Tech Stack

* HTML5
* CSS3
* JavaScript

## Pages Included

* Home
* About Us
* Destinations
* Packages
* Contact Us

## How to Run

1. Download or clone the repository
2. Open `index.html` in your browser
